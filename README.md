# 📊 QUICK

**QUICK (Queue with Impatient Customers)** — это программное приложение, предназначенное для моделирования, анализа и исследования систем массового обслуживания (СМО) с нетерпеливыми заявками. Система реализует инструменты для задания параметров функционирования СМО, проведения аналитических и численных расчетов, а также визуализации результатов моделирования.

Приложение позволяет исследовать поведение систем обслуживания, в которых заявки могут покидать систему до момента начала обслуживания (так называемые **нетерпеливые заявки**). Подобные модели широко применяются при анализе телекоммуникационных систем, информационно-измерительных комплексов, сетевых сервисов, вычислительных систем и других систем обработки запросов.

QUICK предоставляет удобный веб-интерфейс для задания параметров системы и проведения вычислительных экспериментов. Пользователь может задавать интенсивность поступления заявок, интенсивность обслуживания, интенсивность ухода заявок из очереди, а также ограничения на размер системы и другие параметры. На основе этих данных приложение формирует математическую модель системы массового обслуживания и выполняет расчет вероятностных характеристик.

Система поддерживает моделирование различных режимов функционирования СМО, включая **стационарные и переходные режимы**, что позволяет исследовать как установившееся поведение системы, так и динамику изменения ее состояний во времени. Для решения математических моделей используются аналитические методы и численные алгоритмы.

В результате моделирования QUICK вычисляет основные характеристики эффективности системы, среди которых:

- вероятности состояний системы;
- вероятность отказа и потери заявок;
- вероятность обслуживания заявки;
- вероятность ухода заявки из системы;
- среднее число заявок в системе;
- пропускная способность системы;
- абсолютная и относительная пропускная способность.

Полученные результаты могут быть представлены в виде **графиков и визуальных зависимостей**, что позволяет наглядно анализировать влияние параметров системы на ее производительность. Это облегчает проведение исследований, оптимизацию параметров системы и принятие инженерных решений.

Таким образом, QUICK представляет собой инструмент для проведения вычислительных экспериментов и анализа систем массового обслуживания с нетерпеливыми заявками, обеспечивая удобную настройку параметров модели, выполнение расчетов и визуализацию результатов.

## ⚙️ Конфигурация приложения

QUICK использует модуль конфигурации на базе [Pydantic](https://pydantic.dev/) для загрузки параметров из переменных окружения или файла `.env`. Это позволяет гибко настраивать поведение приложения без изменения кода. Приложение не требует строгого наличия `.env` файла.

### 🗄 Основные параметры конфигурации

| Переменная окружения | Описание                           | Значение по умолчанию                                  |
| -------------------- | ---------------------------------- | ------------------------------------------------------ |
| `DISABLE_CACHE`      | Отключение кеширования             | `False`                                                |
| `DUCKDB_PATH`        | Путь к базе данных DuckDB          | `cache_data.duckdb`                                    |
| `DISABLE_LOGGING`    | Отключение логирования             | `False`                                                |
| `LOG_LEVEL`          | Уровень логирования                | `INFO`                                                 |
| `LOG_PATH`           | Путь для записи логов              | Пустая строка                                          |

### ✍️ Пример `.env.example`

```env
DISABLE_CACHE=True
DUCKDB_PATH=cache_data.duckdb
DISABLE_LOGGING=False
LOG_LEVEL=INFO
LOG_PATH=
```

## 🛠️ Установка и запуск

### 💻 Локальный запуск

1. Убедитесь, что у вас установлен Python 3.12 или выше.
2. Установите зависимости:

   ```bash
   uv sync --group web
   ```

3. Запустите приложение:

   ```bash
   streamlit run web/app.py
   ```

### 🐳 Запуск в Docker

1. Соберите Docker-образ:

   ```bash
   docker build -t quick-system .
   ```

2. Запустите контейнер:

   ```bash
   docker run -it --rm -p 8501:8501 \
        -v $(pwd)/cache:/app/cache \
        quick-system
   ```

### 🤖 Использование Taskfile

Для упрощения работы с проектом можно использовать `Taskfile.yml`. Убедитесь, что у вас установлен [Task](https://taskfile.dev/).

1. Установите зависимости:

   ```bash
   task sync
   ```

2. Запустите приложение:

   ```bash
   task run
   ```
